# BreachQR

BreachQR 是一个通过屏幕二维码传输文件的 WPF 原型。程序带文件路径启动时持续显示二维码；不带参数启动时作为接收端，扫描窗口覆盖区域并恢复文件。

## 喷泉编码

传输协议为 `BQR2`，使用 LT 喷泉码：

- 文件按 1200 字节划分为等长源分片，最后一片补零。
- 前 `K` 个包是系统包，分别直接承载一个源分片，便于无丢包时快速完成。
- 后续包按鲁棒孤波分布选择若干源分片并逐字节异或，可无限生成。
- 源分片索引由会话 ID 和包序号确定性生成，二维码无需携带索引列表。
- 接收端先进行剥离解码；方程数量足够时使用 GF(2) 高斯消元兜底。
- 每个包使用 CRC32 排除损坏数据，完整文件使用 SHA-256 验证。

因此接收端不需要等待发送端重新轮播某个固定分片。即使错过全部系统包，也可以只接收后续修复包恢复文件。

## 使用

发送文件：

```powershell
BreachQR.exe "C:\path\to\file.bin"
```

接收文件：

```powershell
BreachQR.exe
```

将接收窗口中间的透明区域覆盖到发送端二维码上。恢复完成后，文件写入：

```text
文档\BreachQR Received
```

同名文件不会覆盖，程序会自动添加数字后缀。
